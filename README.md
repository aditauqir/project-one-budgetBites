# project-one-budgetBites

This is our undergraduate project for Mobile App Development. We picked Budget Bites because buying food and drinks around campus adds up fast. We want to see what we spent and what money is still left.

## Current progress

We added the Flutter starter files and made the screen designs. Right now the app still has the starter counter screen. The screens below are the plan, they are not working features yet. We are doing the proposal first.

## Planned features

- Home: money left, food we can buy, and places around campus.
- Activity: a day budget and a checklist for what we plan to buy.
- Log: add something new, use a saved item, or pick from a menu.
- History: spending bars and the list of things we bought.
- Settings: name, university, budgets, nutrition goals, and saved items.
- Save meals and purchases on the phone with SQLite. Use SharedPreferences for settings.
- Filter food by cuisine and budget. Show a price estimate from earlier purchases, with a way to change it.

## Run the starter

Set up Flutter and an Android phone or emulator, then run:

```sh
flutter pub get
flutter run
```

## Check the starter

```sh
flutter analyze
flutter test
```
